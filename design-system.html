Regras invioláveis transcritas do manual v1.1. A integridade gráfica é sempre mantida — as assinaturas não podem ser distorcidas, alongadas ou alteradas sob nenhuma hipótese.

06 · Tokens

Tokens & componentes

Modelo de três níveis: componentes consomem o token semântico, nunca o primitivo. Trocar de modo ou tema não toca no código do componente.

/* primitivo → semântico → componente */
--color-brick-60: #CC3121;         /* primitivo */
--color-brand-primary: var(--color-brick-60);
--button-primary-bg: var(--color-brand-primary);

/* estado :hover aumenta o contraste, nunca reduz */
.btn-primary:hover{
  background: #A82C1D;   /* 6.90:1 */
}
// button-primary — DTCG
{
  "background": "{color.brand.primary}",
  "background-hover": "{color.brand.primary-hover}",
  "text": "#FFFFFF",   // 5.21:1 AA
  "min-height": "44px",  // 2.5.8
  "radius": "{radius.md}",
  "focus-ring": "3px solid {focus-ring}"
}
